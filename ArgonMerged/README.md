# ArgonWeather

A BepInEx mod for **Gorilla Tag** that adds a **time-of-day and rain changer**
to the in-game **Argon** VR menu. No extra window, no keyboard — everything is
done with the controllers.

## What it does

Open the Argon menu and a new **Customisation** page appears:

- **Heure du jour** — Normal (game), Morning, 10 AM, Day, Evening, Night
- **Pluie** — ON / OFF

The chosen time is **pinned**: it stays applied even when the server resyncs
the room. Pick *Normal* to give control back to the game.

## Controls

| Input | Action |
|---|---|
| **B** (right secondary) | Open / close the menu |
| **A** (right primary) | Select the highlighted item |
| Right stick (up/down) or grips | Move the cursor |

## Install

1. Install **BepInEx** (5.x) in Gorilla Tag.
2. Drop `ArgonWeather-1.0.dll` into `BepInEx/plugins/`.
3. Launch the game and press **B**.

No other dependency is required — the mod is fully self-contained.

## How it works

The mod merges two things into **one single DLL**: the Argon menu and the
time / weather logic of a time-changer mod.

Time is changed through the game's own `BetterDayNightManager`:

- a preset calls `SetTimeOfDay(index)` and pins it with
  `SetTimeIndexOverrideFunction(...)`, which is why it survives server updates;
- *Normal* calls `UnsetTimeIndexOverrideFunction()` + `ClearTimeOfDay(true)`.

Rain uses `SetFixedWeather(WeatherType.Raining, true)` /
`ClearFixedWeather(true)` — the native weather path.

Everything is **local** (no network RPC), so you do not need to be host.

### Menu architecture

- `ArgonMenu.cs` — controller input (B/A/stick), page stack, world-space canvas.
- `MenuApi.cs` — `RegisterRootItem(name, factory)` / `UnregisterRootItem(name)`.
- `WeatherMenu.cs` — the *Customisation* page (hours + rain).
- `Plugin.cs` — BepInEx entry point.

## Known issues

- The time-changing code was **generated by an AI**, so bugs are likely.
- The exact hour presets may be slightly off in game (e.g. "10 AM"). They are
  easy to tune in `WeatherMenu.cs` (`TimeIndex` array).
- If something is broken, please open an issue.

## Build

With the .NET SDK:

    dotnet build -c Release

Set your game path in `Directory.Build.props` (`GamePath`). Without the SDK, the
project also compiles with Roslyn `csc.exe` against the game assemblies
(`Gorilla Tag_Data/Managed`) and `BepInEx/core`, excluding `0Harmony20.dll`.
